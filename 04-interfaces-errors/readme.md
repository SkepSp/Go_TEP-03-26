# Практическая работа № 3. Структуры, методы и указатели

Курс «Бэкенд-разработка на языке Go».   

## Окружение

- Операционная система: Windows 10
- Версия Go: go1.27.2 windows/amd64
- Редактор: visual studio code

## Выполнено

- Реализован интерфейс TaskStore и хранилище MemoryStone
- Реализован метод Add
- Реализован метод Get
- Реализован метод Complete
- Инициализирован Delete
- Реализован метод List
- Добавлена 5 команда - Get

## Запуск программы

```text
go run ./cmd/task-cli/
```

## Проверенные данные

| Шаг | Действие | Ожидается |
|---|---|---|
| 1 | Показать список сразу после запуска | Пуст |
| 2 | Добавить `Изучить Go`, приоритет 2 | ID=1, статус new |
| 3 | Добавить название из одних пробелов | Ошибка, ID не расходуется |
| 4 | Добавить приоритет 0 и 4 | Ошибка |
| 5 | Добавить `Написать API`, приоритет 3 | ID=2 |
| 6 | Завершить ID=1 | Статус done |
| 7 | Завершить ID=1 повторно | Статус done, ошибки нет |
| 8 | Завершить ID=99 | Сообщение об отсутствующей задаче |
| 9 | Удалить ID=1 | Остался ID=2 |
| 10 | Удалить ID=1 снова | Ошибка ErrNotFound |
| 11 | Добавить новую задачу | ID=3 |
| 12 | Ввести неизвестную команду | Подсказка, цикл продолжается |
| 13 | Ввести 0 | Сообщение из defer и выход |
