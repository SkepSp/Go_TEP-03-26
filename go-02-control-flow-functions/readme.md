# Практическая работа № 2. Условия, циклы, функции и коллекции

Курс «Бэкенд-разработка на языке Go».

## Окружение

- Операционная система: Windows 10
- Версия Go: go1.27.2 windows/amd64
- Редактор: visual studio code

## Выполнено

- Сводка статусов задач
- Функция перевода статуса
- Нумерованный список
- Функция подсчёта
- Словарь частот

## Запуск программы

```text
go run ./cmd/task-summary/
```

## Проверенные данные

| Сценарий | Временно задайте `statuses` | `append` | Что проверить |
|---|---|---|---|
| 1. Обычный | `{"new", "in_progress", "done", "done"}` | Включён (`new`) | Всего 5, завершено 2, статистика 2/1/2 |
| 2. Пустой список | `[]string{}` | Временно отключён | Всего 0, ни одной нумерованной строки, завершено 0, частоты 0/0/0 |
| 3. Одна задача | `[]string{"done"}` | Временно отключён | Всего 1, завершено 1, частоты 0/0/1 |
| 4. Нет завершённых | `[]string{"new", "new"}` | Временно отключён | Всего 2, завершено 0, частоты 2/0/0 |
