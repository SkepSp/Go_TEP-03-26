- Инициализирован срез из 3х объектов

## Проверенные данные

| Сценарий | Ожидаемый результат |
|---|---|
| Поиск ID=2 | Получен ненулевой указатель |
| `Complete()` по ID=2 | Во **всём срезе** статус этой задачи `done` |
| `SetPriority(3)` | `true`, приоритет изменён |
| `SetPriority(0)` | `false`, прежний приоритет сохранён |
| `SetPriority(4)` | `false`, прежний приоритет сохранён |
| Поиск ID=99 | `nil`, без паники |
| Поиск в `[]Task{}` | `nil` |
| `Task{}` | Все поля имеют нулевые значения |
